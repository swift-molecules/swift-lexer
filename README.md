# swift-lexer

Use this package to turn a borrowed byte span into tokens without copying it. To lex Swift-like source into `Token.Kind` values with byte ranges and trivia lengths, start from `Lexer.Scanner` and call `next(diagnostics:)` until it returns `nil`. To read a different format (JSON, YAML) as a stream of format-specific events with a nesting limit, conform a type to `Lexer.Pull.Tokens`, drive it with `Lexer.Pull.Stream`, and build values with a `Lexer.Pull.Assemble.Strategy` through `Lexer.Pull.Assemble.from(_:strategy:)`.

## Laws

- `Lexer.Scanner` reads bytes, not characters: only ASCII letters, digits and `_` form identifiers, and each byte it does not recognise, including each byte of a non-ASCII UTF-8 character, becomes its own `.unknown` lexeme with an `.invalidCharacter` diagnostic.
- `Lexer.Scanner.next(diagnostics:)` never stops on an error. It appends the diagnostic and keeps lexing. It returns exactly one `.endOfFile` lexeme, with an empty range at the end of the source that carries the final leading trivia, and returns `nil` on every call after that.
- Leading trivia is everything before a token that is a space, tab, vertical tab, form feed, LF, CR, CR LF, `//` comment, or `/* */` comment. Block comments nest. Trailing trivia is only the spaces and tabs after a token on the same line. A line break always belongs to the next token's leading trivia.
- An unterminated block comment consumes the rest of the source and is reported at its `/*`. A string literal is single-line: it ends at the closing `"`, at an unescaped line break, which it does not consume, or at the end of the source. In the last two cases it is still `.stringLiteral` and is reported as unterminated at its opening quote. A backslash escapes whatever byte follows it.
- A word that spells a keyword in `Token.Keyword` is always lexed as `.keyword`, including contextual words such as `get`, `set` and `any`. A lone `_` is `.wildcard`. `$` followed by zero or more digits is `.dollarIdentifier`.
- `->` and `...` are single lexemes. A byte from `= ! ? & ~` that starts a lexeme is a one-byte lexeme, so `==` is two `.equal`. Any other operator byte starts a `.binaryOperator` that runs over the following operator bytes, these five included, and `.`, so `<=` and `+=` are one lexeme each.
- A number is `.floatingLiteral` only when a `.` is followed by a digit or when an `e`/`E` exponent follows. `1.foo` is an integer, a period and an identifier. `0x`, `0b` and `0o` start integer literals. `_` separators are accepted between digit groups.
- `#if`, `#else`, `#elseif` and `#endif` are single lexemes. Any other `#` is `.pound`, and the word after it is lexed on its own.
- `Lexer.Scanner.location` is tracked incrementally, and only from newlines that `next(diagnostics:)` passes or that a caller reports through `newline(at:)`. `advance()`, `advance(by:)` and `consume()` record no newlines. `Lexer.Scanner.location(at:)` and `Lexer.Pull.Stream.position(at:)` cache nothing: each call rescans from the start of the source and counts LF bytes.
- `Lexer.Pull.Stream` does not enforce its `limit`. It passes `depth` and `limit` to the `Lexer.Pull.Tokens` conformer. The conformer's `next(scanner:depth:limit:)` must update `depth` and throw once it would pass `limit`, and its `skip(value:depth:limit:)` must consume exactly one complete value.
- `Lexer.Pull.Stream.peek()` skips whitespace, so it moves the scanner, but it leaves the stream pristine. `next()`, `skip()`, `consume(via:)` and `touch()` all clear `isPristine`.
- `Lexer.Pull.Stream.consume(via:)` hands its closure the whole original span and the limit, whatever the scanner has already read. Only if the closure returns does the stream become consumed, and from then on `next()` returns `nil`.
- `Lexer.Pull.Assemble.from(_:strategy:)` calls the strategy's `consume(bytes:limit:)` on the whole input when the stream is pristine. Otherwise it calls `build(events:)` on the events that remain. A strategy must return the same value from both paths for the same pristine input.
